# BioBanker — Biobank & Biospecimen Management System

## Project topic
**Biobank and Biospecimen Management System**

This project models a small research biobank that manages donors, consent, biospecimen collection, storage, aliquots, researchers, test requests, and sample usage.

## DBMS
PostgreSQL 15+ (also compatible with recent PostgreSQL versions).

## Alignment with the supplied reference

The report and presentation intentionally follow the same clear academic flow as the supplied medicine-inventory example: **Introduction → ERD → Schema → DDL Codes → DML Codes → SQL Queries → Views/Advanced Object → Testing → Conclusion**. The database topic remains the approved Biobank and Biospecimen Management System rather than copying the reference topic.

## Main features
- Donor and consent management
- Biospecimen collection tracking
- Storage location tracking
- Sample and aliquot inventory
- Researchers and test requests
- Many-to-many sample/test-request relationship through `sample_test_requests`
- Sample usage history
- Two reporting views
- Trigger that prevents over-use of aliquots and automatically updates remaining volume
- Primary keys, foreign keys, UNIQUE, CHECK, and NOT NULL constraints
- Indexes for common searches
- Queries covering joins, aggregation, subqueries, INSERT, UPDATE, and DELETE

## Setup
1. Create an empty PostgreSQL database, for example:
   `CREATE DATABASE biobanker;`
2. Connect to the database.
3. Run the scripts in this order:
   1. `sql/create_tables.sql`
   2. `sql/triggers_procedures.sql`
   3. `sql/views.sql`
   4. `sql/load_data.sql`
   5. `sql/testing.sql`
   6. `sql/queries.sql`
4. Confirm that the testing script reports PASS for all automated checks and capture the required pgAdmin screenshots.
